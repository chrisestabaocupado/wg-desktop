# Inter

Fuente Inter de The Inter Project Authors, incluida sin modificar bajo SIL Open
Font License 1.1. La licencia completa acompaña al archivo en `OFL.txt`.

Origen: [Inter en Google Fonts](https://github.com/google/fonts/tree/main/ofl/inter).

La aplicación incrusta `Inter.ttf`; no requiere descargas de fuentes ni fuentes
instaladas en Windows. Las fuentes predeterminadas de egui se conservan como fallback.
